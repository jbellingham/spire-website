# Screenshots for the page

Five JPEGs, about 1600 px wide, 16:9. Drop each in here with the name below, then in `index.html` replace that slot's
`<div class="slot">…</div>` with `<img src="shots/NAME.jpg" alt="…">` and keep the caption.

| File | What it shows |
|---|---|

| `street.jpg` | The street at night looking up at HELIX: shop signs, umbrellas, the dark tower and the drone ring in the cloud |
